MacIsland

A native Dynamic Island for the MacBook notch. Media controls, a file shelf, calendar, timer, battery and live activities — in a black shape that grows out of the notch and disappears back into it.

Download for macOS View on GitHub

macOS 14 Sonoma or later · Apple silicon & Intel · free and open source

What it does

▭

Lives in the notch

Collapsed, it is the notch. Hover to peek, keep hovering or click to open, move away to close. Interruptible spring animations, 120 Hz ready.

♫

Media controls

Apple Music and Spotify: artwork, title, scrubber, play/pause, previous/next, bars tinted with the album colour. Event-driven, zero polling.

⤓

File shelf

Drag files onto the notch to park them, drag them back out into any app, reorder, Quick Look, open. Persistent across launches.

▦

Calendar

Today at a glance and the next seven days of events with your calendar colours and a “Now” badge.

◷

Timer & battery

Presets, pause and resume, a progress ring and a notification at the end. Battery level, charging state and remaining time.

◉

Live activities

Track changes, volume and mute, power plugged or unplugged, low battery, running timer and file drops appear in the notch’s wings.

Install

  1. Download the .dmg from the latest release.
  2. Drag MacIsland to Applications.
  3. First launch: right-click the app and choose Open (the build is signed ad hoc, not notarized).
  4. Allow Automation for Music / Spotify and Calendars when macOS asks.

No Dock icon: use the notch icon in the menu bar for Settings (⌘,) and Quit.

Build from source

git clone https://github.com/HarenaFiantso/MacIsland.git
cd MacIsland
open MacIsland.xcodeproj   # ⌘R

# UI-free core tests
cd Packages/IslandCore && swift test

Xcode 16 or later. No dependencies, no private APIs.

How it works

  • One borderless, non-activating NSPanel per display floats above the menu bar. The SwiftUI island sits on a fixed-size canvas; the panel is just a viewport that shrinks to the notch when idle, so nothing outside the notch can steal a click.
  • A pure, unit-tested state machine decides when to peek, open and close; springs are described by stiffness and damping and converted to interpolating SwiftUI animations that keep their velocity when interrupted.
  • Everything is event-driven: player notifications, EventKit changes, IOKit power callbacks, Core Audio listeners. Idle CPU is 0 %.

Honest limits: no browser or VLC playback (macOS has no public now-playing API for third parties), no brightness activity (no public API), and the bars are an animation, not a spectrum analyser.
